# 测试计划：当前版本回归

## 测试目标

验证人工批注、AI 辅助检查、导出、删除、清空、通知和隐私边界符合当前需求基线。

## 测试准备

1. 在 `chrome://extensions/` 重新加载扩展。
2. 刷新测试网页。
3. 准备四类页面：普通正文页、跨节点文本页、无正文/复杂导航页、`tests/fixtures/snapshot-long.html` 本地长页面。
4. AI 测试优先使用 Mock 测试模式；真实服务测试另行验证网络和权限。

## 基础访问

### TC-BASE-001 本地 HTML 权限

- 关闭插件“允许访问文件网址”，打开 `tests/fixtures/snapshot-long.html`，Popup 应禁用页面操作并给出完整开关路径。
- 开启权限并刷新本地 HTML，Popup 能读取标题和 URL，能进入批注模式、发起 Mock AI 检查并导出。
- `chrome://extensions/` 和 Chrome 商店仍显示受保护页面提示。

## 核心人工批注

### TC-MANUAL-001 标记点反馈

- 添加标记点反馈。
- 保存后页面出现编号，Popup 列表出现反馈，悬浮球数量增加。
- 非文本反馈不显示引用文本。

### TC-MANUAL-002 区域反馈

- 框选区域并保存。
- 默认只显示编号。
- 悬停或点击编号时显示区域框和详情。
- 局部截图证据存在且不变形。

### TC-MANUAL-003 文本反馈

- 选中文本并保存文本反馈。
- 填写卡片显示引用文本。
- 页面原文附近显示蓝色下划线标记。
- Popup 列表显示引用文本。

### TC-MANUAL-004 删除单条反馈

- 从 Popup 删除人工反馈。
- 从页面详情删除人工反馈。
- 两种删除都需要确认。
- 删除后页面标记、Popup 数量、导出内容同步更新。

### TC-MANUAL-005 清空当前页

- 当前页存在人工反馈和 AI 待确认结果时点击清空。
- 当前 URL 的人工反馈和 AI 结果全部移除。
- 其他 URL 的数据不受影响。

## 页面交互

### TC-UI-001 边缘填写卡片

- 在页面底部、右侧和右下角创建反馈。
- 分类、输入框和保存按钮都在视口内可操作。

### TC-UI-002 悬浮入口

- 拖动悬浮入口到左右两侧。
- 松手后吸附侧边。
- 鼠标移开后半隐藏，靠近或悬停后完整显示。
- 刷新后恢复上次位置。

### TC-UI-003 快捷键冲突

- 普通区域按 `Ctrl+Alt+1/2/3/E` 可触发对应动作。
- 输入框、textarea、select 和可编辑区域聚焦时不触发。
- `Esc` 可取消当前动作或关闭菜单。

## AI 辅助检查

### TC-AI-001 未配置 AI

- 清空 AI 设置后点击“开始检查”。
- 不发起网络请求。
- 显示 AI 设置引导或明确错误。
- 人工批注仍可使用。

### TC-AI-002 保存设置与权限

- 配置智谱、DeepSeek、Google Gemini、自定义服务或 Mock。
- 保存后设置保留。
- API Key 不明文回填完整值。
- 非 Mock 服务按 Base URL 请求可选域名权限。
- 已配置后可从 AI 功能区重新进入设置；从智谱切换到 Gemini 且未填写新 Key 时不得保存旧智谱 Key。

### TC-AI-002B Gemini 原生协议

- 选择 Google Gemini，使用有效 Key 和 `gemini-3.5-flash` 执行检查。
- 请求地址应为 `.../models/gemini-3.5-flash:generateContent`，使用 `x-goog-api-key`，不发送 Bearer 鉴权。
- 将旧设置保存为 `custom + https://generativelanguage.googleapis.com/v1beta` 后重新加载，应自动使用 Gemini 原生适配。

### TC-AI-003 Mock 检查

- 使用 `tests/fixtures/ai-normal.html` 或含“确诊按钮 / Lorem ipsum / 重复重复”的页面。
- 启用 Mock 测试模式。
- 检查后生成待确认 AI 结果。
- 能定位原文的结果显示琥珀色下划线。

### TC-AI-004 无法定位结果

- 使用跨节点文本页面或构造 AI 返回无法精确匹配的文本。
- 结果进入反馈清单。
- 页面不绘制错误坐标标记。
- 日志能说明未定位原因。

### TC-AI-005 确认 AI 问题

- 打开 AI 待确认详情，点击 `加入反馈`。
- AI 结果从待确认列表移除。
- 新增一条正式人工反馈。
- 新反馈可删除、可导出，页面标记按人工反馈样式显示。

### TC-AI-006 非问题删除

- 点击 AI 详情中的 `非问题`。
- 该 AI 结果从页面和 Popup 中移除。
- 导出 HTML/PDF 不包含该条。

### TC-AI-007 关闭 Popup 后继续

- 发起 AI 检查后立即关闭 Popup。
- 页面右下角进度持续显示。
- 检查完成后重新打开 Popup，可看到最终结果。

### TC-AI-008 请求失败与重试

- 配置错误 Key、断网或使用会超时的服务。
- 检查应自动重试。
- 全部失败时显示持久中文错误。
- 错误提示提供关闭和复制日志入口。
- 不残留半成品标记。

### TC-AI-008B 返回格式容错

- 模拟 AI 返回 `{"items":[]}`、`[]`、Markdown JSON 代码块和 `未发现问题。`。
- 插件应正常解析，不显示错误。
- 模拟 AI 连续返回不可解析文本。
- 插件应自动重试，最终显示中文格式异常提示。

### TC-AI-009 通知

- 允许 Chrome 系统通知后执行一次成功检查。
- 检查完成后出现系统通知。
- 禁用 Chrome 通知或系统勿扰后再执行一次检查。
- 页面/日志应出现中文通知失败原因，而不是静默无反馈。

### TC-AI-010 低错建议质量

- 构造文本：`这个文件夹属是有点深不可测`。
- 即使模型返回 `属是 -> 似乎`，插件侧也不能展示该语义改写。
- 期望结果：展示 `属是 -> 属实`，或在无法确认时不生成 AI 标记。
- 构造文本：`我感觉这个方案可行`，模型返回 `感觉 -> 认为` 时应被过滤，不进入页面标记和清单。

## 导出

### TC-EXPORT-001 快照 HTML

- 从旧版本重新加载 0.5.15，确认 Chrome 对新增 `debugger` 权限的提示可正常完成，扩展保持启用。
- 添加标记点、区域和文本反馈后导出快照 HTML。
- HTML 可独立打开。
- 主体为截图快照。
- 右上角“修改点全览”显示反馈内容、分类和日期。
- 点击条目跳转并高亮对应标记。
- 使用 `tests/fixtures/snapshot-long.html` 验证截图从顶部连续到页面底部。
- 验证 HTML 快照路径发送 `CAPTURE_FULL_PAGE_CDP`，不发送 `CAPTURE_VISIBLE_TAB`。
- 固定顶部导航只出现一次，吸顶章节标题不因 CDP 分片重复覆盖后续正文。
- 超长页面分片使用固定文档坐标，截图片段之间没有卡片间距、空洞或重复内容。
- 模拟 `Page.captureScreenshot` 失败，确认 `chrome.debugger.detach` 仍被调用并显示中文解决建议。
- 在目标页打开 DevTools 后触发导出，应提示关闭开发者工具；关闭后重试可正常导出。

### TC-EXPORT-002 PDF

- 分别测试只有人工反馈、只有 AI 待确认结果、两者同时存在。
- 人工反馈在前，AI 待确认结果在最后。
- 已加入反馈的 AI 结果按人工反馈展示。
- 非问题不导出。
- 截图不拉伸，日期不显示时分秒，不显示坐标。

## 隐私边界

- AI 请求体只包含文本块，不包含截图、人工反馈数据和页面截图。
- 本地存储只写入 `chrome.storage.local`。
- 导出文件只在用户主动触发时生成。
