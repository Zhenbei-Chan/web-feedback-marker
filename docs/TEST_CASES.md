# 测试用例

本文档记录网页反馈标注器发布前需要执行的核心回归测试。当前项目暂无构建步骤，测试以 Chrome 开发者模式手动验证为主。

## 测试前准备

1. 打开 `chrome://extensions/`。
2. 重新加载网页反馈标注器。
3. 打开一个普通 `https://` 网页。
4. 点击插件图标，确认弹窗能读取当前页面标题和 URL。
5. 点击“进入批注模式”。

## TC-001 添加标记点反馈

**目标**：验证标记点反馈可以保存，并在页面和弹窗中同步显示。

步骤：

1. 点击页面右下角铅笔悬浮球。
2. 选择“添加标记”。
3. 点击页面任意位置。
4. 填写分类和反馈内容。
5. 点击“保存”。
6. 打开插件弹窗。

预期结果：

- 页面上出现编号标记。
- 悬浮球数量加 1。
- 弹窗反馈清单出现该反馈。
- 弹窗“共 x 条”数量正确。

## TC-002 添加区域反馈

**目标**：验证区域框选反馈可以保存截图证据。

步骤：

1. 点击铅笔悬浮球。
2. 选择“框选区域”。
3. 拖拽框选页面区域。
4. 填写分类和反馈内容。
5. 点击“保存”。
6. 打开插件弹窗。

预期结果：

- 页面上出现编号标记。
- 悬停编号时显示区域框和反馈详情。
- 弹窗反馈清单出现该反馈。
- 反馈卡片中包含局部截图。

## TC-003 添加文本反馈

**目标**：验证只有文本反馈显示引用文本。

步骤：

1. 在网页中选中一段文字。
2. 点击铅笔悬浮球。
3. 选择“文本反馈”。
4. 填写分类和反馈内容。
5. 点击“保存”。
6. 打开插件弹窗。

预期结果：

- 反馈填写卡片显示引用文本。
- 弹窗反馈清单显示引用文本。
- 标记点反馈和区域反馈不显示引用文本。

## TC-004 删除单条反馈

**目标**：验证从弹窗删除单条反馈后，页面标记、数量和导出内容同步更新。

步骤：

1. 在同一页面添加 3 条反馈。
2. 打开插件弹窗。
3. 删除第 2 条反馈。
4. 回到网页查看页面标记。
5. 导出 PDF。

预期结果：

- 删除前会出现确认提示。
- 弹窗反馈数量从 3 变为 2。
- 页面内编号标记重新连续显示。
- 悬浮球数量变为 2。
- PDF 不包含已删除反馈。

## TC-005 页面内删除单条反馈

**目标**：验证从页面内反馈详情删除单条反馈后，弹窗和 storage 同步更新。

步骤：

1. 在页面中添加至少 2 条反馈。
2. 点击或悬停页面编号，展开反馈详情。
3. 点击“删除这条反馈”。
4. 确认删除。
5. 打开插件弹窗。

预期结果：

- 页面内对应编号消失。
- 剩余编号重新连续显示。
- 弹窗反馈清单同步减少 1 条。
- 弹窗“共 x 条”数量正确。

## TC-006 清空当前页反馈

**目标**：验证清空当前页后，弹窗数量、页面标记和悬浮球数量同步清零。

步骤：

1. 在当前页面添加至少 2 条反馈。
2. 保持页面批注浮层处于开启状态。
3. 打开插件弹窗。
4. 点击“清空当前页”。
5. 回到网页查看页面标记和悬浮球数量。
6. 再次打开插件弹窗。

预期结果：

- 弹窗反馈清单显示“暂无反馈”。
- 弹窗数量显示“共 0 条”。
- 页面内编号标记全部消失。
- 悬浮球数量显示 0。
- 导出 PDF 按钮置灰。
- 清空当前页不会影响其他 URL 的反馈。

## TC-007 清空后重新添加反馈

**目标**：验证清空后可以重新开始当前页反馈收集。

步骤：

1. 执行 TC-006 清空当前页反馈。
2. 在当前页面重新添加 1 条标记点反馈。
3. 打开插件弹窗。

预期结果：

- 新反馈编号从 1 开始。
- 弹窗数量显示“共 1 条”。
- PDF 导出只包含清空后新增的反馈。

## TC-008 PDF 截图比例

**目标**：验证不同截图比例导出 PDF 时不拉伸变形。

步骤：

1. 添加一个横向区域反馈。
2. 添加一个竖向区域反馈。
3. 添加一个标记点反馈。
4. 导出 PDF。

预期结果：

- 横向截图按宽度适配。
- 竖向截图按高度约束展示。
- 标记点截图保持原始比例。
- 所有截图没有明显拉伸变形。

## TC-009 边缘位置反馈填写卡片

**目标**：验证页面底部、右侧或角落创建反馈时，填写卡片仍可编辑和保存。

步骤：

1. 滚动到页面底部。
2. 在页面底部附近添加标记点反馈。
3. 在页面右侧附近添加标记点反馈。
4. 在页面右下角附近框选区域。

预期结果：

- 反馈填写卡片不会超出视口。
- “保存”按钮始终可点击。
- 文本框和分类选择器可正常操作。

## TC-010 快捷键冲突回归

**目标**：验证快捷键只在非输入状态下触发。

步骤：

1. 进入批注模式。
2. 聚焦网页普通区域，按 `Ctrl+Alt+1`。
3. 聚焦反馈输入框，按 `Ctrl+Alt+1`。
4. 聚焦网页可编辑输入框，按 `Ctrl+Alt+2`。

预期结果：

- 普通区域按快捷键可以触发对应批注动作。
- 输入框或可编辑区域聚焦时，不触发批注快捷键。
