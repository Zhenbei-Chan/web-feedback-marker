# 测试用例

本文档记录网页反馈标注器发布前需要执行的核心人工批注回归测试。完整当前版本回归计划见 `docs/08_TEST_PLAN.md`，验收标准见 `docs/09_ACCEPTANCE.md`。当前项目暂无构建步骤，测试以 Chrome 开发者模式手动验证为主。

## 测试前准备

1. 打开 `chrome://extensions/`。
2. 重新加载网页反馈标注器。
3. 打开一个普通 `https://` 网页。
4. 点击插件图标，确认弹窗能读取当前页面标题和 URL。
5. 点击“进入批注模式”。

## TC-001 添加标记点反馈

**目标**：验证标记点反馈可以保存，并在页面和弹窗中同步显示。

步骤：

1. 点击页面右下角铅笔悬浮球。
2. 选择“添加标记”。
3. 点击页面任意位置。
4. 填写分类和反馈内容。
5. 点击“保存”。
6. 打开插件弹窗。

预期结果：

- 页面上出现编号标记。
- 悬浮球数量加 1。
- 弹窗反馈清单出现该反馈。
- 弹窗“共 x 条”数量正确。

## TC-002 添加区域反馈

**目标**：验证区域框选反馈可以保存截图证据。

步骤：

1. 点击铅笔悬浮球。
2. 选择“框选区域”。
3. 拖拽框选页面区域。
4. 填写分类和反馈内容。
5. 点击“保存”。
6. 打开插件弹窗。

预期结果：

- 页面上出现编号标记。
- 悬停编号时显示区域框和反馈详情。
- 弹窗反馈清单出现该反馈。
- 反馈卡片中包含局部截图。

## TC-003 添加文本反馈

**目标**：验证只有文本反馈显示引用文本。

步骤：

1. 在网页中选中一段文字。
2. 点击铅笔悬浮球。
3. 选择“文本反馈”。
4. 填写分类和反馈内容。
5. 点击“保存”。
6. 打开插件弹窗。

预期结果：

- 反馈填写卡片显示引用文本。
- 弹窗反馈清单显示引用文本。
- 标记点反馈和区域反馈不显示引用文本。

## TC-004 删除单条反馈

**目标**：验证从弹窗删除单条反馈后，页面标记、数量和导出内容同步更新。

步骤：

1. 在同一页面添加 3 条反馈。
2. 打开插件弹窗。
3. 删除第 2 条反馈。
4. 回到网页查看页面标记。
5. 导出 PDF。

预期结果：

- 删除前会出现确认提示。
- 弹窗反馈数量从 3 变为 2。
- 页面内编号标记重新连续显示。
- 悬浮球数量变为 2。
- PDF 不包含已删除反馈。

## TC-005 页面内删除单条反馈

**目标**：验证从页面内反馈详情删除单条反馈后，弹窗和 storage 同步更新。

步骤：

1. 在页面中添加至少 2 条反馈。
2. 点击或悬停页面编号，展开反馈详情。
3. 点击“删除这条反馈”。
4. 确认删除。
5. 打开插件弹窗。

预期结果：

- 页面内对应编号消失。
- 剩余编号重新连续显示。
- 弹窗反馈清单同步减少 1 条。
- 弹窗“共 x 条”数量正确。

## TC-006 清空当前页反馈

**目标**：验证清空当前页后，弹窗数量、页面标记和悬浮球数量同步清零。

步骤：

1. 在当前页面添加至少 2 条反馈。
2. 保持页面批注浮层处于开启状态。
3. 打开插件弹窗。
4. 点击“清空当前页”。
5. 回到网页查看页面标记和悬浮球数量。
6. 再次打开插件弹窗。

预期结果：

- 弹窗反馈清单显示“暂无反馈”。
- 弹窗数量显示“共 0 条”。
- 页面内编号标记全部消失。
- 悬浮球数量显示 0。
- 导出 PDF 按钮置灰。\n- 若当前页存在 AI 待确认结果，也会一并清空。
- 清空当前页不会影响其他 URL 的反馈。

## TC-007 清空后重新添加反馈

**目标**：验证清空后可以重新开始当前页反馈收集。

步骤：

1. 执行 TC-006 清空当前页反馈。
2. 在当前页面重新添加 1 条标记点反馈。
3. 打开插件弹窗。

预期结果：

- 新反馈编号从 1 开始。
- 弹窗数量显示“共 1 条”。
- PDF 导出只包含清空后新增的反馈。

## TC-008 PDF 截图比例

**目标**：验证不同截图比例导出 PDF 时不拉伸变形。

步骤：

1. 添加一个横向区域反馈。
2. 添加一个竖向区域反馈。
3. 添加一个标记点反馈。
4. 导出 PDF。

预期结果：

- 横向截图按宽度适配。
- 竖向截图按高度约束展示。
- 标记点截图保持原始比例。
- 所有截图没有明显拉伸变形。
- 报告头部固定展示“网页反馈标注报告”，并包含反馈数量、导出时间和页面来源。
- 每条反馈以信息流方式展示，主标题为“标注点 x”，分类、类型和时间作为小字信息。
- PDF 不展示反馈位置或页面坐标。
- 反馈内容紧跟标注点信息，截图证据紧跟反馈内容。
- 每页底部包含页脚和页码。

## TC-009 HTML 导出

**目标**：验证当前页面可以导出为带批注的网页快照 HTML 报告。

步骤：

1. 添加至少 3 条反馈，覆盖标记点、区域框选和文本反馈。
2. 打开插件弹窗。
3. 点击“导出快照 HTML”。
4. 打开下载的 HTML 文件。
5. 点击右上角“修改点全览”里的不同修改点。

预期结果：

- HTML 文件可以正常打开。
- 页面主体使用截图快照保留原网页视觉上下文。
- 页面上显示蓝色编号标记。
- 右上角显示“修改点全览”和“共 x 条”。
- 修改点列表以反馈内容为主，分类和时间为辅助信息。
- 点击修改点后页面跳转到对应标注位置。
- 当前修改点和页面标记有高亮状态。
- 截图证据可以在修改点详情中查看。

## TC-009A 导出当前页全量反馈

**目标**：验证导出不依赖本次新增反馈，而是导出当前页面已有的全部反馈。

步骤：

1. 在页面 A 添加 2 条反馈。
2. 退出批注模式。
3. 刷新页面 A。
4. 不新增任何反馈，直接打开插件弹窗。
5. 分别点击“导出快照 HTML”和“导出 PDF”。

预期结果：

- 两种导出都可以执行。
- 导出的报告都包含页面 A 已有的 2 条反馈。
- 不出现“本次还没有新保存的反馈”之类的阻断提示。

## TC-009B 导出时间隐私

**目标**：验证导出报告默认不暴露精确标注时间。

步骤：

1. 添加至少 1 条反馈。
2. 导出快照 HTML。
3. 导出 PDF。
4. 检查报告中的反馈元信息。

预期结果：

- 反馈元信息只展示日期。
- 不展示小时、分钟、秒。
- 文件名仍可按发布规则保留生成时间，便于区分导出文件。

## TC-010 边缘位置反馈填写卡片

**目标**：验证页面底部、右侧或角落创建反馈时，填写卡片仍可编辑和保存。

步骤：

1. 滚动到页面底部。
2. 在页面底部附近添加标记点反馈。
3. 在页面右侧附近添加标记点反馈。
4. 在页面右下角附近框选区域。

预期结果：

- 反馈填写卡片不会超出视口。
- “保存”按钮始终可点击。
- 文本框和分类选择器可正常操作。

## TC-011 快捷键冲突回归

**目标**：验证快捷键只在非输入状态下触发。

步骤：

1. 进入批注模式。
2. 聚焦网页普通区域，按 `Ctrl+Alt+1`。
3. 聚焦反馈输入框，按 `Ctrl+Alt+1`。
4. 聚焦网页可编辑输入框，按 `Ctrl+Alt+2`。

预期结果：

- 普通区域按快捷键可以触发对应批注动作。
- 输入框或可编辑区域聚焦时，不触发批注快捷键。

## TC-012 悬浮入口拖动与吸附

**目标**：验证页面内铅笔悬浮入口可以移动位置，并在非使用状态下降低遮挡。

步骤：

1. 进入批注模式。
2. 拖动右下角铅笔悬浮入口到页面左侧。
3. 松开鼠标。
4. 将鼠标移开悬浮入口。
5. 再次移动鼠标靠近悬浮入口。
6. 点击悬浮入口打开菜单。
7. 刷新页面后重新进入批注模式。

预期结果：

- 拖动过程中悬浮入口跟随鼠标移动。
- 松开后悬浮入口吸附到最近侧边。
- 鼠标移开后悬浮入口半隐藏到侧边，减少遮挡。
- 鼠标靠近或悬停时悬浮入口完整显示。
- 菜单打开时悬浮入口和菜单完整显示。
- 重新进入批注模式后，悬浮入口恢复到上次保存的侧边和高度。
- 拖动行为不影响框选区域、添加标记和文本反馈。

## TC-013 悬浮入口自动避让

**目标**：验证页面内铅笔悬浮入口不会默认压住网页已有的侧边悬浮组件。

步骤：

1. 打开一个带右下角客服、返回顶部或登录悬浮组件的网页。
2. 进入批注模式。
3. 观察铅笔悬浮入口初始位置。
4. 将铅笔悬浮入口拖到已有悬浮组件附近并松开。
5. 打开铅笔悬浮菜单。
6. 将铅笔悬浮入口拖到另一侧边。

预期结果：

- 铅笔悬浮入口不会默认压在同侧已有悬浮组件上。
- 拖动到已有悬浮组件附近后，松手会在同侧寻找邻近可用位置。
- 菜单打开时铅笔入口位置稳定，不会被菜单自身向下挤开。
- 自动避让不影响手动拖动、侧边吸附、半隐藏和 hover 展开。
- 如果页面没有可识别的 `fixed` / `sticky` 浮层，悬浮入口保持用户选择的位置。
