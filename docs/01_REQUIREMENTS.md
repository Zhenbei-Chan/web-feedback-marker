# 当前需求基线

本文档记录网页反馈标注器 0.5.13 本地版本的当前产品需求基线，用于后续迭代、验收和回归测试。若实现与本文档冲突，以本文档为目标口径，除非另有新的需求确认。

## 产品定位

网页反馈标注器是一个本地优先的 Chrome Manifest V3 扩展，用于在网页走查、内容审核、产品验收和视觉检查时，直接在网页上下文中记录反馈，并导出可分享的反馈报告。

核心原则：

- 边浏览边批注，尽量不打断原网页浏览。
- 本地优先，人工反馈、AI 设置和截图证据默认保存在 `chrome.storage.local`。
- 默认不启用 AI；AI 检查必须由用户主动配置自己的服务和 API Key。
- 不做账号系统、云同步、内置服务端、遥测统计。
- 默认权限尽量少，AI 服务域名使用可选授权。

## 当前功能范围

### 人工反馈

- 读取当前页面标题、URL 和选中文字。
- 支持标记点反馈、区域框选反馈、文本反馈。
- 支持问题分类：内容错误、表达不清、结构问题、链接问题、视觉建议、其他。
- 反馈填写卡片只保留分类和反馈内容，不再单独提供“修改建议”字段。
- 非文本反馈不显示引用文本。
- 文本反馈保存后，页面内优先使用贴近原文的下划线标记；无法定位时才退回普通点位标记。
- 区域反馈保存后，默认只显示编号；悬停或点击时显示区域框和反馈详情。
- 标记点反馈保存后显示低打扰编号/图钉标记。
- 支持从弹窗或页面反馈详情删除单条人工反馈。
- 支持清空当前页人工反馈和 AI 待确认结果。

### 页面批注入口

- 进入批注模式后，页面出现铅笔悬浮入口。
- 悬浮入口支持拖动、侧边吸附、半隐藏、靠近或悬停时完整显示。
- 悬浮入口尽量避让网页已有的固定/粘性浮层。
- 悬浮菜单提供：框选区域、添加标记、文本反馈、AI 检查页面、导出快照 HTML、退出批注。
- 快捷键：`Ctrl+Alt+1` 框选，`Ctrl+Alt+2` 标记，`Ctrl+Alt+3` 文本，`Ctrl+Alt+E` 导出快照 HTML，`Esc` 取消或关闭菜单。
- 快捷键在输入框、下拉框、文本域和可编辑区域聚焦时不触发。

### AI 辅助检查

- Popup 和页面悬浮菜单均提供“AI 检查页面”。
- 未配置时进入 AI 设置流程；已配置后才发起检查。
- 支持智谱 AI、DeepSeek、OpenAI-compatible 自定义服务和 Mock 测试模式。
- API Key 只保存在本地 `chrome.storage.local`，开源代码不内置 Key。
- AI 检查只发送抽取后的可见正文文本块，不上传截图、人工反馈数据或页面截图。
- 默认优先检查正文区域，尽量跳过导航、目录、页脚、推荐列表等公共区域。
- 严格低错模式：优先保留错别字、错字、别字、多字、漏字、重复字、标点错误、占位文本、日期/数字/单位等客观高确定性问题。
- 过滤主观表达优化、风格建议、标题吸引力建议、普通改写建议和低置信度结果。
- AI 结果默认进入“待确认”状态。
- 能精确定位原文时，在页面原文下方显示琥珀色手绘下划线和编号。
- 无法精确定位时，结果保留在反馈清单中，但不在页面上绘制坐标标记。
- 用户点击“加入反馈/确认问题”后，AI 结果转为正式人工反馈，并从 AI 待确认列表移除。
- 用户点击“非问题”后，删除该 AI 结果，不进入导出报告。
- AI 检查运行中，页面右下角显示持续进度；Popup 关闭后页面检查继续。
- AI 检查完成或失败时，尝试发送系统通知；若通知权限不可用，需要在日志中记录中文原因。
- 请求超时、网络错误、5xx 和限流错误会自动重试；单个文本块失败不应中断整页检查，除非全部文本块失败。

### 导出报告

- 快照 HTML 是优先推荐的分享格式。
- 快照 HTML 以导出时的页面截图为主体，不复制原网页 DOM，不依赖原站样式重新排版。
- 快照 HTML 右上角提供“修改点全览”，以反馈内容为主，分类和日期为辅助信息，点击后跳转到对应标记。
- PDF 是清单型补充报告，适合归档和异步传阅。
- PDF 优先展示人工反馈；仍处于待确认的 AI 结果放在文档最后的“AI 检查结果”区域。
- 已确认的 AI 结果因为已转为人工反馈，所以按人工反馈展示。
- 被标记为非问题的 AI 结果不导出。
- 报告默认不展示页面坐标。
- 报告中的反馈时间默认只展示日期，不展示具体时分秒。
- PDF 文件名格式：`网页名称前 20 个字符 - yyyyMMdd - HHmm - 反馈标注.pdf`。

## 非目标

- 不自动修改原网页。
- 不做 OCR，因此无法识别图片里的文字错误。
- 不做多人实时协作。
- 不做账号系统、云端同步、团队空间。
- 不承诺第三方 AI 服务免费或稳定。
- 不把 API Key 上传到作者或项目维护者服务器。

## 隐私与权限

- 人工反馈、截图证据、AI 设置和 AI 结果保存在 `chrome.storage.local`。
- `notifications` 权限仅用于 AI 检查完成或失败后的系统通知。
- `optional_host_permissions` 仅在用户配置 AI 服务并保存时按服务域名请求。
- 用户导出的 HTML/PDF 文件由用户自行保存和分享。
