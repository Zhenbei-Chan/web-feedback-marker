# 网页反馈标注器 UI 规范

## 设计原则

- 浏览优先：默认不拦截网页滚动、点击和文本选择。
- 低打扰：不需要批注时，页面只保留一个可吸附的铅笔入口。
- 按需展开：工具菜单、填写卡片、反馈详情和帮助说明都按需出现。
- 就近处理：标记后在标记附近补充反馈，避免跳出页面上下文。
- 状态可感知：AI 检查、导出、删除、通知失败等状态必须有明确反馈。

## 插件弹窗

弹窗定位是“当前页面控制台”，不承担沉浸式批注本身。

信息层级：

1. 顶部：插件图标、名称“网页反馈标注器”、副标题“当前页面反馈收集与导出”、右上角帮助入口。
2. 当前页面：页面标题和 URL 作为灰色上下文注释，不使用白底卡片包裹。
3. 主操作：`进入批注模式` 为唯一强主按钮。
4. AI 辅助检查：独立浅色区块，按钮为 `开始检查`。未配置时引导设置。
5. 导出报告：`快照 HTML` 与 `PDF` 并列，快照 HTML 是推荐分享格式。
6. 页面管理：`清空当前页反馈` 使用低权重危险操作样式。
7. 反馈清单：标题右侧显示 `共 x 条，AI y 条`。
8. 状态区：展示成功、失败、通知失败、日志复制入口。

帮助说明和快捷键默认折叠到问号入口；首次使用或用户主动展开时显示。

## 页面悬浮入口

- 默认位置：右下角，距视口边缘 18px。
- 形态：圆形蓝色按钮，中心为白色铅笔图标。
- 数量徽标：显示当前页人工反馈数量。
- 行为：可拖动，松手后吸附最近侧边；鼠标移开后半隐藏，靠近或悬停时完整显示。
- 避让：尽量避让网页已有 `fixed` / `sticky` 浮层，无法识别时保留用户选择位置。

## 悬浮菜单

菜单项：

- 框选区域：拖拽选择页面区域，快捷键 `Ctrl+Alt+1`。
- 添加标记：点击页面位置，快捷键 `Ctrl+Alt+2`。
- 文本反馈：先选中网页文字，快捷键 `Ctrl+Alt+3`。
- AI 检查页面：生成待确认 AI 标记。
- 导出快照 HTML：导出截图快照报告，快捷键 `Ctrl+Alt+E`。
- 退出批注：关闭页面批注入口。

快捷键在输入框、文本域、下拉框和可编辑区域聚焦时不触发。

## 反馈填写卡片

字段：

- 分类：下拉框，标签内嵌展示。
- 反馈内容：textarea，占位文案为“反馈：描述问题、原因或建议”。
- 引用文本：仅文本反馈场景展示；标记点和区域反馈不展示。
- 按钮：`保存`。

位置：

- 优先靠近标记点、框选区域或选中文本。
- 靠近底部、右侧或角落时自动向可视区域内调整，保证分类、输入框和保存按钮可操作。

行为：

- 保存后关闭填写卡片，回到浏览模式。
- 取消后删除当前未保存草稿。

## 页面标记

人工反馈：

- 标记点：图钉/编号标记，低打扰显示。
- 区域反馈：默认只显示编号；悬停或点击时显示区域框和详情。
- 文本反馈：优先使用贴近文字的蓝色下划线标记；旧数据或无法定位文本时退回普通点位标记。

AI 待确认：

- 使用琥珀色手绘下划线和小编号，贴近原文文本矩形。
- 鼠标悬停或点击展示详情浮层。
- 无法精确定位时，不在页面上绘制标记，只保留在反馈清单中。

## 反馈详情浮层

触发：

- hover 临时展开。
- click 固定展开，再次点击取消固定。

内容：

- 人工反馈：序号、分类、日期、反馈内容、引用文本、删除按钮。
- AI 结果：序号、错误类型、待确认状态、原因、原文、建议、`加入反馈`、`非问题`。

行为：

- 点击 `加入反馈` 后，AI 结果转为正式人工反馈，并从 AI 待确认列表移除。
- 点击 `非问题` 后，删除 AI 结果。
- 删除人工反馈后，页面标记、弹窗列表、导出内容同步更新。

## AI 检查进度

- 页面右下角是唯一详细进度入口。
- Popup 只提示“AI 检查进行中，进度见页面右下角”。
- 进度不展示互相矛盾的字数和百分比，优先展示稳定进度条、当前阶段和已处理时长。
- 错误提示不自动消失，需提供关闭按钮和复制日志入口。
- 检查完成或失败时尝试系统通知；通知不可用时，状态日志记录中文原因。

## HTML 快照报告

设计目标：

- 给没有安装插件的人查看反馈。
- 用导出时截图保留原页面视觉上下文，避免原网页 DOM 重排导致标记错位。
- 右上角固定“修改点全览”，以信息流方式展示反馈。

内容：

- 页面截图快照。
- 编号标记和区域高亮。
- 右上角修改点全览。
- 反馈内容、分类、日期、引用文本、截图证据。
- 原页面标题、URL、导出日期和快照说明。

交互：

- 点击修改点跳转到对应标记位置。
- 当前项使用浅蓝背景和左侧蓝色边线高亮。

## PDF 报告

设计目标：

- 面向归档、邮件传递和异步评审。
- 信息流布局，减少大面积矩形卡片。
- 不展示页面坐标。

规则：

- 文件名：`网页名称前 20 个字符 - yyyyMMdd - HHmm - 反馈标注.pdf`。
- 字体优先使用 HarmonyOS Sans / 鸿蒙黑体，缺失时回退系统中文字体。
- 人工反馈在前；待确认 AI 结果在最后。
- 已确认 AI 结果转为人工反馈后，按人工反馈展示。
- 日期默认不展示具体时分秒。
- 截图按原始宽高比缩放，避免横图、竖图或长图变形。
