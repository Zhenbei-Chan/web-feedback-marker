# 网页反馈标注器 UI 规范

## 设计原则

- 默认低打扰：批注模式开启后，页面右下角只保留一个悬浮球。
- 浏览优先：默认不拦截网页滚动、点击、选择文本。
- 按需展开：只有点击悬浮球时展示工具菜单。
- 一次性动作：选择“框选区域”或“添加标记”后，完成一次标注即自动回到浏览模式。
- 就近填写：生成标注草稿后，反馈填写卡片出现在标记附近，而不是常驻占用侧边空间。

## 常驻入口

- 位置：右下角，距视口边缘 18px。
- 尺寸：52px 圆形按钮。
- 图标：按钮中心显示白色铅笔图标。
- 数量：右上角小徽标显示当前页已保存反馈数量。
- 展开菜单：点击悬浮球后向上展开操作列表。

## 插件弹窗

- 定位：作为工具门面，优先说明当前页面状态和进入批注的主路径。
- 顶部：使用插件图标、插件名称、使用定位和右上角帮助入口。
- 外层：插件页面自身使用圆角矩形、细边框和轻阴影；Chrome 弹窗系统容器不作为可控设计对象。
- 当前页：页面标题和 URL 作为灰色上下文注释展示，不使用白底卡片包裹。
- 主操作：保留“进入批注模式”为唯一强主按钮。
- 次操作：保留“导出 PDF”和“清空当前页”，无反馈时置灰。
- 信息层级：反馈数量跟随“反馈清单”标题展示为“共 xx 条”，不单独占用数字卡片。
- 辅助信息：首次使用展开使用说明和快捷键；用户收起或进入批注模式后，后续默认折叠到帮助入口。
- 反馈列表：作为当前页摘要，避免抢占主操作空间。

## 悬浮菜单

菜单项：

- 框选区域：拖拽标出页面区域，全局快捷键 `Ctrl+Alt+1`。
- 添加标记：点击页面上的具体位置，全局快捷键 `Ctrl+Alt+2`。
- 文本反馈：先选中网页文字，全局快捷键 `Ctrl+Alt+3`。
- 导出本次 PDF：导出当前批注会话中新保存的反馈，全局快捷键 `Ctrl+Alt+E`。
- 退出批注：关闭页面内批注入口。
- 取消当前动作或关闭悬浮菜单：快捷键 `Esc`。
- 快捷键在输入框、文本框、下拉框和网页可编辑区域聚焦时不触发，避免打断正常输入。

菜单视觉：

- 白色浮层，12px 圆角，轻阴影。
- 每个菜单项为 48px 最小高度。
- 主标题 14px，说明文字 12px。
- hover 使用浅蓝背景和浅蓝边框。

## 页面标记

区域标记：

- 使用轻量半透明底色 + 矩形描边。
- 已保存状态默认只显示编号，不常驻显示区域框。
- 鼠标悬停或点击编号时，才显示红色实线区域框和四角短角标。
- 未保存草稿为蓝色短虚线，四角有短角标。
- 编号圆点位于区域左上角。

点位标记：

- 使用图钉式标记，外层有半透明定位光晕。
- 已保存状态为红色，草稿状态为蓝色。
- 编号圆点贴近图钉右上方。

编号标记：

- 直径 30px。
- 红底白字，2px 白色描边。
- 支持 hover 放大。
- hover 或 click 展开反馈详情。

## 反馈详情浮层

触发：

- 鼠标悬停编号：临时展开。
- 点击编号：固定展开，再次点击取消固定。

内容：

- 序号 + 问题分类。
- 反馈时间。
- 反馈内容。

视觉：

- 宽度 310px。
- 白色背景，10px 圆角，轻阴影。
- 位置优先靠近编号，自动限制在视口内。

## 反馈填写卡片

触发：

- 框选区域结束后出现。
- 添加标记点后出现。
- 文本反馈创建后出现。

字段：

- 问题分类内置在下拉框中，不单独占用标题行。
- 反馈内容使用输入框占位提示，不单独占用标题行。
- 引用文本状态，仅在文本反馈场景出现。
- 非引用场景不显示引用文本模块。

行为：

- 保存后自动关闭卡片，回到浏览模式。
- 取消后删除当前未保存草稿，回到浏览模式。

## 截图规则

区域反馈：

- 截取框选区域并向四周外扩 72px。
- 若靠近视口边缘，自动裁到可视范围内。

标记点和文本反馈：

- 截取标记点周边 640×360 CSS 像素。
- 视口不足时自动缩小。

## PDF 清单

设计目标：

- 让报告可以直接交给产品、设计、研发沟通，不暴露插件内部坐标信息。
- 每条反馈都形成“问题是什么 → 在哪里 → 证据截图”的闭环。
- 信息密度要高，但避免把截图、说明、元信息混在一起。
- 字体优先使用鸿蒙黑体 / HarmonyOS Sans，系统不存在时回退到本机中文字体。

标题格式：

- `网页名称前 20 个字符 - yyyyMMdd - HHmm - 反馈标注`

每条反馈包含：

- 序号。
- 问题分类。
- 反馈时间。
- 反馈内容。
- 反馈位置，使用“框选区域 / 标记点附近 / 文本引用附近”等用户可理解描述，不展示页面坐标。
- 局部截图。

版式建议：

- 顶部展示“反馈标注报告”、报告标题、页面 URL、导出时间、反馈数量。
- 每条反馈使用独立分隔线、蓝色编号块、分类标签和反馈类型。
- 反馈内容优先于截图，截图作为证据跟随在文字后。
- 引用文本使用浅灰底块，和普通反馈内容区分。
- 截图使用浅灰边框和圆角，避免与页面内容混淆。
- 截图按原始宽高比缩放并在正文区域居中展示，不强制铺满整行。
- 横向截图优先适配正文宽度；竖向截图优先适配最大展示高度；超宽长条图按宽度适配，避免垂直空间浪费。
